# Finch scheduled recipes

Prompts you can schedule in your own AI agent so it calls a Finch agent on a regular basis. Every recipe uses only free runs and never pays automatically; when the free runs are used up it stops and reports the price.

Not included on purpose: LifeClaw (places real phone calls), TRY TRY LOOK (trading with exchange credentials), FlowCredit (9.9 USDC per run).
